# ♿ Accessibility Statement

We are committed to making **crystalcastleX** usable and accessible to everyone, regardless of ability, device, or assistive technology.

---

## 🎯 Our Goal
- Meet **WCAG 2.1 Level AA** — the global gold standard
- Support all modern browsers + common assistive technologies
- Keep interfaces simple, consistent, and easy to navigate
- Provide clear feedback and helpful error messages

---

## ✅ What We Maintain

| Area | Standard |
|---|---|
| **Color contrast** | Minimum **4.5:1** for normal text (WCAG AA) |
| **Keyboard navigation** | All interactive elements reachable via `Tab` / arrow keys |
| **Focus indicators** | Visible, high-contrast focus rings — never removed |
| **Screen readers** | All images have descriptive alt text; form fields have proper labels |
| **Semantic HTML** | Use `<nav>`, `<main>`, `<button>`, `<section>` — not just `<div>` |
| **Links** | Descriptive link text — no "click here" or "read more" |
| **Responsive** | Works on mobile, tablet, desktop; text scales to 200% without breaking |
| **Motion** | Respect `prefers-reduced-motion` — disable heavy animations when requested |

---

## 🧪 How We Test
- ✅ Manual keyboard testing (`Tab`, `Shift+Tab`, `Enter`, `Space`, arrow keys)
- ✅ Built-in browser dev tools (Lighthouse, Accessibility Insights)
- ✅ Color contrast checkers
- ✅ Screen reader compatibility testing where available
- ✅ Cross-browser / device responsiveness checks

---

## ⚠️ Known Limitations
We’re working to fix these — contributions welcome!

| Item | Status |
|---|---|
| Older browsers (IE11) | Not supported — upgrade recommended |
| Complex data visualizations | Improving label & keyboard support |
| Auto-generated documentation | Audit in progress |

---

## 📢 Report an Accessibility Barrier
If you find something that's hard or impossible to use:

**Preferred method:**
👉 Open a [GitHub Issue](https://github.com/zyntromedia/crystalcastleX/issues) — label it **`accessibility`**

**Include:**
- What you were trying to do
- What happened / what blocked you
- Device + browser you're using
- Any assistive technology in use

**Timeline:**
- We'll acknowledge within **48 hours**
- We'll aim to fix critical barriers within **7 days**
